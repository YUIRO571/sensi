# Enterprise SQL Analytics & Database Engine

An end-to-end relational database project built using **Microsoft SQL Server**. This project models an E-Commerce platform to analyze sales performance, customer purchasing behavior, and transactional data using advanced SQL concepts.

## 🛠️ Key SQL Concepts Demonstrated
* **DDL & Schema Design:** Normalized tables (3NF), Primary & Foreign Keys, Constraints (`CHECK`, `DEFAULT`).
* **Advanced Aggregations & Joins:** Multi-table INNER/LEFT JOINs, GROUP BY, and aggregate metrics.
* **Window Functions & CTEs:** Customer segmentation, ranking, and running totals.
* **Database Optimization:** Indexing and execution performance tuning.

## 📁 Repository Structure
* `schema.sql` — Database creation, table definitions, and constraints.
* `seed_data.sql` — Sample transactional data for testing.
* `analytics_queries.sql` — Complex queries and business insights.
